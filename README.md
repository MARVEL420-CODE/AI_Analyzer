# ASCIA — Aerospace & Space Supply Chain Intelligence MVP

A React + Vite frontend with Framer Motion animations and an Express backend that calls the Gemini API. The default model is Gemini 4 Argon (`gemini-4-argon`); Google model availability can vary by API project and region. It creates a preliminary, component-specific risk report, compliance research checklist, quality checks, payment controls, logistics checks, workflow steps, and future scenarios.

## Requirements
- Node.js 20+ recommended
- A Gemini API key from Google AI Studio with access to the configured model
- Internet access for package installation and Gemini requests

## Run locally

1. Extract this project ZIP.
2. Open a terminal in the project folder.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Create your local environment file:

   **macOS/Linux**
   ```bash
   cp .env.example .env
   ```

   **Windows PowerShell**
   ```powershell
   Copy-Item .env.example .env
   ```

5. Open `.env` and replace `replace_with_your_gemini_api_key` with your key:

   ```env
   GEMINI_API_KEY=your_real_key_here
   GEMINI_MODEL=gemini-4-argon
   PORT=8787
   ```

6. Start frontend and backend together:

   ```bash
   npm run dev
   ```

7. Open the Vite URL shown in the terminal, usually `http://localhost:5173`.

## Gemini model configuration
- Default model: `gemini-4-argon`, listed by Google as its flagship reasoning model. See the [official Gemini API model list](https://ai.google.dev/gemini-api/docs/models).
- To use a different model available to your API key, change `GEMINI_MODEL` in `.env` and restart the server.
- If the API returns a model-not-found or access error, check model access for your Google AI Studio/API project and choose an available model from Google’s current list.

## Security notes
- The Gemini key is read by the Express backend and is never included in frontend code.
- Never place a secret key in a `VITE_*` variable, commit `.env`, or share the key in screenshots/chats.
- Rotate the key immediately if it is accidentally exposed.
- Add authentication, rate limiting, tenant isolation, server-side input limits, monitoring, and deployment secret management before public launch.
- Do not upload controlled technical data, export-controlled drawings, or confidential customer documents until the hosting, model provider terms, data residency, retention and authorization controls have been reviewed.

## Current limitations
- Gemini generates the report, but the app does **not** have a live web-search connector. It instructs the model to disclose this and to mark source/applicability checks for verification.
- Source URLs generated by the model are not guaranteed to be current or verified. Open and validate official sources before acting.
- The report is decision support only, not legal advice, an export-control classification, airworthiness approval, engineering qualification or quality release.
- This prototype does not persist reports to a database. Reports can be exported as a text file.
- No real supplier, shipment, certificate, registry, ERP, carrier, payment or customs system is connected yet.
